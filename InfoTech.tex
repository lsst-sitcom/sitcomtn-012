\section{Information Technology}

The Information Technology (IT) team in Chile uses four platforms for documentation:

\begin{itemize}

	\item The IT tech note series, ITTN: \url{https://www.lsst.io/ittn/}. Note: IT is are actively moving from writing Confluence pages to using ITTN documents more and more.
	\item README files in GitHub repositories in \url{https://github.com/lsst-it/}. For example, https://github.com/lsst-it/k8s-cookbook contains procedures for standing up and operating various Kubernetes clusters.
	\item Confluence; primarily for day-to-day communications exchange with the Commissioning and Camera teams.
	\item DocuShare, as required by the project.
	
\end{itemize}
